# Requirements with no evidence named

**99 of 232 requirements (43%) name no document in the tracker.** That is not proof
nothing exists — but at audit, an evidence column an auditee cannot fill in seconds is a gap.
Starred (★) requirements are listed first: the auditor must write an explanation for these in the
report **even when they score A**, so they get asked about by design.
